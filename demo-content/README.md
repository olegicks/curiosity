# Demo content (local testing only)

Lessons here exist so the app can be tried on a device with several subjects
(D-17) and an estimate challenge (D-18). They are **not editorially reviewed**:
reviewers are marked "Demo", and nothing here may be imported into staging or
production. Citations in `sources.yaml` point to real publications.

```bash
cd apps/api
uv run curiosity content import --dir ../../demo-content
```
